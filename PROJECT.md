# Graph Engineering Study — project contract

## Main goal

Study and build a deterministic-first software-engineering graph that creates mature scaffolding quickly and reserves coding-model inference for hard semantic repair.

## Scope

- exact source locks for the Pukujan stack and selected OSS;
- real ACS/OIO adoption path rather than copied governance files;
- app-builder-automation's React/Vite/shadcn substrate as the GUI starting point;
- typed local control flow with Pydantic Graph;
- deterministic validation and structured evidence;
- a bounded, pluggable coding-worker edge;
- later Dagger, Nx, OpenHands, and Hatchet experiments.

## Non-goals

- replacing ACS, OIO, PCM, CGM, or ABA;
- asking an LLM to author boilerplate already represented by a generator/template;
- treating model review as a substitute for build/test evidence;
- running an unbounded autonomous repair loop;
- committing downloaded OSS into this repository.

## Success rule

A graph run succeeds only when its deterministic validation gate succeeds. A coding worker may modify the workspace, but it cannot declare success.
